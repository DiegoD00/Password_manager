# 🔐 Python Password Manager (CLI)

A simple command-line password manager built in Python that allows users to store, view, and search account credentials.

## 📌 Features
- Add new account credentials (website, username, password)
- View all saved accounts
- Search for accounts by website
- Stores data locally in a text file

## ⚙️ Technologies Used
- Python
- File handling (text file storage)

## 🚀 How to Run
Clone the repository to your local machine and run the main Python file. The program will open in your terminal with a menu of options.

## 📁 Project Structure
The project includes a main Python file for the application logic and a text file where account data is stored.

## 🧠 How It Works
User credentials are stored in a text file in a simple format. The program reads from and writes to this file to manage account data. Users can search for accounts by entering a website name.

## ⚠️ Disclaimer
This project is intended for educational purposes only. Passwords are stored in plain text and are not secure.
